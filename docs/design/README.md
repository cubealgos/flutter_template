# App design

The approved UI design for the template's app (approved 2026-09-26). The sources of the
reviewable canvas are kept here.

- `spec.md`: global rules (grid, breakpoints, typography, colour, borders) and one section per
  screen. §2.4 is superseded by the onboarding stepper mockups.
- `tokens-needed.md`: the token and component changes the spec needs in `core/design/ui`.
- `mockups/`: the artboards (`<Screen>-<device>-<theme>.dc.html`) and `canvas.json`, the layout of
  the canvas.
