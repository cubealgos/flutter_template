# api

Generated by `dart run tooling:map`. Do not hand-edit.

Path: `backend/appwrite/functions/api`

Appwrite Function: the one `api` action router. Authenticates the caller, dispatches `{"action": "...", ...}` to a registered action (delete_account, review_demo_sign_in, team_admin, ...) and maps errors; also runs scheduled jobs on the cron tick. Deployed with `dart run bin/deploy.dart api` from `backend/appwrite/tool/`.
