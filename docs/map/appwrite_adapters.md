# appwrite_adapters

Generated by `dart run tooling:map`. Do not hand-edit.

Path: `backend/appwrite/adapters`

Appwrite adapters for `core/contracts/auth`, `core/contracts/data` and `core/contracts/teams`: `AppwriteAuthService`, `AppwriteDocumentRepository`, `AppwriteStorageService` and `AppwriteTeamService`, backed by the `appwrite` client SDK. This template's default backend wiring (see the plan's decision 4); an app can swap in a different backend by implementing `AuthService`/ `DocumentRepository`/`StorageService` itself instead.
