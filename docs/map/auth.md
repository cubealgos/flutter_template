Backend-agnostic authentication interfaces: `AuthService`, its typed `AuthError` hierarchy, `AuthCapabilities` (what a given backend actually supports), and an in-memory `FakeAuthService` for screens and tests. `backend/appwrite/adapters` implements this against Appwrite; a cloned app can swap in a different backend by implementing `AuthService` itself.
