# billing

Generated by `dart run tooling:map`. Do not hand-edit.

Path: `core/contracts/billing`

Backend-agnostic web billing: `Billing` (start a checkout, open the customer portal, update a subscription's quantity, read the entitlement), the `Entitlement` read model computed from a subscription's state and the current time, the append-only `BillingLedger` and `BillingEngine` (every provider event is written to the ledger before any side effect, so a replay is a no-op), `BillingReconciler` and an in-memory `FakeBilling`. The merchant-of-record adapter is `backend/paddle`.
