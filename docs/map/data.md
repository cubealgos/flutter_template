Path: `core/contracts/data`

Backend-agnostic data interfaces: `DocumentRepository` (per-collection document CRUD, scoped to the current user or, with a `TeamScope`, to a team), `StorageService` (per-user file upload/download/delete), `UserPreferences` (per-user key/value prefs) and `VersionPolicy` (minimum-supported-version check), plus in-memory fakes for screens and tests. `backend/appwrite/adapters` implements all four against Appwrite's `TablesDB`, `Storage` and `Account` services.
