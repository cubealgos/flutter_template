# jobs

Generated by `dart run tooling:map`. Do not hand-edit.

Path: `core/contracts/jobs`

Backend-agnostic leased job queue: `JobQueue` (enqueue with a priority band, claim with a lease, heartbeat, complete, fail, release), `JobQueueEngine` (the one implementation of the rules, built on claim rows with a unique (job id, attempt) key because TablesDB has no compare-and-set), `JobStore` (its persistence seam) and an in-memory `FakeJobQueue` for tests. `backend/appwrite/functions/api`'s `jobs` action runs the engine on Appwrite; `backend/appwrite/adapters`'s `AppwriteJobQueue` calls that action.
