# legal_facts

Generated by `dart run tooling:map`. Do not hand-edit.

Path: `core/contracts/legal_facts`

The template's placeholder legal-entity facts (company name, address, commercial register entry, VAT ID, contact email, responsible person, supervisory authority) as one pure-Dart, Flutter-free source. `apps/app`'s `AppConfig` reads these as its `legal*` fields' defaults, and `apps/website`'s Impressum/Datenschutz pages read them directly, so the two can never drift the way a duplicated `LegalPlaceholders` class did before. Every value is an **obvious placeholder**: a cloned app must replace every field with its own lawyer-reviewed facts before shipping.
