# mailing

Generated by `dart run tooling:map`. Do not hand-edit.

Path: `core/contracts/mailing`

Backend-agnostic transactional and notification email: `Mailer` (send a templated mail to a user with a locale, an idempotency key, headers and a delivery result), `MailerEngine` (the one implementation of the rules over a `MailStore` and a `MailTransport`), `MailCatalog` (de/en templates, pure Dart), `UnsubscribeLinks` (signed, expiring one-click links) and an in-memory `FakeMailer` for tests. `backend/appwrite/functions/api` runs the engine on Appwrite Messaging and direct SMTP.
