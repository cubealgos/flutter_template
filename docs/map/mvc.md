# mvc

Generated by `dart run tooling:map`. Do not hand-edit.

Path: `core/architecture/mvc`

The template's MVC package: a vendored ValueNotifier + InheritedWidget view triad (ViewModel/ViewController/ViewWidget, from sprout_state 0.3.0) plus `ResponsiveLayout` (mobile/tablet/desktop layout picker with fallback) and the injectable services (navigation, external-URL launching, dialogs) a controller uses to reach outside itself without a view ever doing so directly. Views stay dumb and navigate only through injected services; see core/architecture/mvc_lints, which enforces the view boundary this package is built around.
