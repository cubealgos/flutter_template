# tokens_builder

Generated by `dart run tooling:map`. Do not hand-edit.

Path: `core/design/tokens_builder`

A build_runner Builder that turns DTCG design-token JSON (`core/design/ui/tokens/*.json`) into `package:mix` token declarations (`core/design/ui/lib/src/tokens.g.dart`). Deliberately depends only on `package:build` (not `package:analyzer`/`source_gen`) — it reads plain JSON assets, not annotated Dart source, so it never needs the analyzer and never constrains the workspace's analyzer 10.x-13.x pin. The template owns its own copy of the token source rather than depending on a separate design-system repository, and every dimension unit is handled explicitly here rather than through an assumed transform (Style Dictionary's flutter transform group assumes `rem`).
